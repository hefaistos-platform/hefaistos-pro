# OpenTIDE Rule Editor

## Publishing
The rule editor and workbench publish OpenTIDE content through **OpenTIDE HEF**.

Flow:
1. save or update the workbench,
2. generate an OpenTIDE preview,
3. continue to the HEF publish dialog,
4. publish to GitHub,
5. optionally deploy to selected platforms.

## Configuration
Admins should create HEF publish profiles in **Configuration → OpenTIDE HEF**.
