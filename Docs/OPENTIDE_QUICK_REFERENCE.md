# OpenTIDE Quick Reference

## Admin setup
- **Configuration → Rules**: GitHub repository
- **Configuration → OpenTIDE HEF**: publish profile
- **Configuration → Platform Credentials**: optional deployment access

## Analyst flow
- Open workbench
- Generate preview
- Continue to HEF publish
- Select profile/repository
- Publish to GitHub
- Optionally deploy

## Removed legacy path
- No InitTide SSH configuration
- No SSH deploy key setup
- No `commitPlaybookToInitTide`
